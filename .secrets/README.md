# Segredos locais

Esta pasta **não vai para o Git** (exceto este README).

Coloque aqui tokens e chaves. Nunca cole senhas no chat nem no código.

Arquivos esperados:

- `github.token` — Personal Access Token do GitHub (só neste computador)

Permissões recomendadas: pasta `700`, arquivos `600`.

Se um token já apareceu no chat, revogue-o em GitHub → Settings → Developer settings → Personal access tokens e crie outro.
