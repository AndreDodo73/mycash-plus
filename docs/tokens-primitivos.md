# Primitivas — Tokens de Figma

Fonte: [Primitives - Tokens de Figma](https://docs.google.com/spreadsheets/d/1icfTxXdSbtd029FfOYnrlMs2pC8HJqk5PDuEmQF5Zjo/edit?gid=0#gid=0)

Estas são as **variáveis primitivas** do design system. Na implementação:

1. Semântica aplicada no Figma → usar
2. Primitiva desta tabela → usar
3. Hex/px local → converter para a primitiva mais próxima da família
4. Nunca hardcoded

CSS no código: `color/neutral/1100` → `--color-neutral-1100` (barra vira hífen).
